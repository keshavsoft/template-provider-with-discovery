⚙ Generator Flow

Every folder inside the test directory contains its own test.js file.

Running a particular test.js demonstrates one feature of the template generator. Instead of manually creating folders, routes, APIs, and endpoint files, the generator creates them automatically.

1️⃣ fromAppJs


test/
 └── v6/
      └── fromAppJs/
            ├── app.js
            └── test.js

Run


node test/v6/fromAppJs/test.js

Purpose

Reads the application's app.js file and automatically generates the complete API folder structure.

Generated Output


api/
    v1/
📂 Creates api folder
📁 Creates version folders
⚙ Reads app.js

2️⃣ fromRoutesJs


test/
 └── v6/
      └── fromRoutesJs/
            └── test.js

Run


node test/v6/fromRoutesJs/test.js

Purpose

Generates API version routing automatically. 


api/
    v1/
    v2/
    v3/

Each API version receives its own router configuration.

🛣 Creates router.use()
📦 Creates Version Folder
🔄 Updates routes.js

3️⃣fromRoutesEnd


test/
 └── v6/
      └── fromRoutesEnd/
            └── test.js

Run


node test/v6/fromRoutesEnd/test.js

Purpose

Creates a folder for every database table automatically. 


api/
    v1/
        bills/
        items/
        customers/
        products/

Every table receives its own endpoint files and controller structure.

📁 Creates Table Folder
📄 Creates end-points.js
⚙ Ready for CRUD
