📖 Project Overview

This project is built using a JSON Server as the backend database. Instead of using MySQL or MongoDB, all application data is stored inside multiple JSON files. Every table in the application belongs to one of these JSON files, making the project lightweight, easy to understand, and simple to maintain.

📂 JSON Files

Each JSON file represents a collection of related data. For example, one file may contain all master tables, while another stores transaction data. Whenever an API is called, the server reads or writes information from these JSON files.

📋 Tables

Every table inside the JSON file represents a specific business entity, such as Customers, Products, Employees, or Orders. Each table stores records in JSON format and acts like a database table. The APIs communicate directly with these tables to perform CRUD operations.

🌐 APIs

The application exposes REST APIs for every table. These APIs allow the frontend or any external application to interact with the data. Every API has a clear purpose, such as fetching records, creating new entries, updating existing information, or deleting data.

⚡ HTTP Methods

Each API uses standard HTTP methods. GET retrieves data, POST creates new records, PUT updates existing records, and DELETE removes unwanted records. Using these standard methods keeps the API consistent and easy to understand.
