🚀 About This Repository

template-provider-with-discovery is an automation tool for generating Express.js REST APIs. It minimizes repetitive coding by automatically creating the required API structure based on the project configuration and developer inputs.

In a traditional Express.js application, creating a new API requires manually creating folders, endpoint files, routes, controllers, and registering them inside the routing system. This process is repetitive, time-consuming, and prone to human error.

This repository automates the entire API creation process. Using the built-in VS Code extension and generator scripts, developers can create a complete CRUD API with minimal effort. The generator discovers the existing project structure, updates routing files, creates missing folders, and generates the required endpoint files automatically.

🎯 Purpose

The primary goal of this repository is to standardize API development, reduce manual work, and ensure every API follows the same project structure and coding conventions.

⚙ Example

Suppose you want to create an API for the Purchase table. 


GET    /api/v1/purchase/showAll
POST   /api/v1/purchase/insert
PUT    /api/v1/purchase/update
DELETE /api/v1/purchase/delete

Instead of manually creating these routes and related files, the generator automatically builds the required folder structure, endpoint files, routing configuration, and controller references.
